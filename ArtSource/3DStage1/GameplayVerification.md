# 3D 전환 검증

Unity 6000.6.0f1의 `Assets/Scenes/3D.unity`에서 Play Mode로 확인했습니다.
테스트 입력과 체력 변경은 플레이 모드에서만 적용했고 저장하지 않았습니다.

| 항목 | 실제 결과 |
| --- | --- |
| 카메라 기준 전진 | 0.6초에 X 2.40m 이동 |
| 좌우 이동 | 0.6초에 Z -2.40m 이동 |
| 점프 | 3.18m 상승 후 착지 |
| 웅크리기 | 캡슐 높이 1.2m, 다시 일어서기 성공 |
| 대시 | 2.80m 이동 |
| 닫힌 문 | X=20.42에서 정지, X=21 문 통과 불가 |
| Z 방향 무기 피해 | 소총 3, 산탄총 4, 검 3, 충전 검 20 |
| 지속 피해 | 3회 합계 1.5 |
| 몬스터 추적 | 0.5초에 Z -0.64m 이동 |
| 보스 탄막 | 24개 발사, 그중 22개에 Z 방향 성분 존재 |
| 회복 지점 | 같은 X의 먼 Z에서는 회복 안 됨; 실제 접근 시 90→100, 1회 소모 |
| 카메라 장애물 | 문 앞에서 추적 거리 약 1.33m로 단축 |
| 구간 진행 | 7개 전투 구간 완료, 문 7개 개방 |
| 출구 | 같은 X의 먼 Z에서는 미완료, 실제 출구 접근 시 완료 |

피해 수치는 개별 대상에게 명중한 값입니다. 산탄총 모든 탄환이 한 대상에 맞는 상황을 가정하지 않습니다.
보스 탄막 검사는 실제 발사 경로를 호출해 확인했습니다. 장시간 전투 난이도와 바다 맵 플레이는 별도 조정 대상입니다.

기존 Side View 생성기와 검증 스크립트 6개는 자동 승인 검토에서 삭제가 거부되어 `ArtSource/LegacyTools`에 텍스트로 보관했습니다. Unity에서는 컴파일하거나 사용하지 않습니다.
기존 Test_Scene과 Stage02_Sea 씬도 영구 삭제가 거부되어 `ArtSource/LegacyScenes`에 원본과 메타데이터를 텍스트로 보관했습니다. Stage01_Forest와 사용 참조가 0개인 Side View 전용 TowerDungeon, PlayerSideView 에셋은 삭제했습니다. 리깅 모델과 텍스처는 Player3D에 보존했습니다.
