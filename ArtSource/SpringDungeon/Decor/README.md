## 구성

2번 만개한 꽃밭 보스룸: 뒤편 꽃 제단과 아치, 꽃 기둥, 주변 화단과 작은 꽃 군집 (49개).

기존 방 크기/바닥/벽/통로는 유지했습니다. 각 방의 Decor 그룹에서 개별 프리팹을 편집할 수 있습니다. 부모의 비균일 확대는 Decor 그룹에서 상쇄해 구조물 비율을 보존했습니다. 원본 USDZ는 그대로 남아 있습니다.

## 최적화

원본 합계 60,000 → 58,112 삼각형 (3.15% 감소). 15종으로 분리했습니다. 꽃잎과 덩굴 형태가 민감하여 감소량보다 형태 보존을 우선했습니다. 최대 양방향 정점-표면 샘플 오차는 모듈 최대 길이의 0.6% 이내입니다. 전체 표면에 대한 수학적 보증은 아닙니다. 원본 UV와 베이스 컬러/노멀 이미지를 유지하고 USDZ별로 이미지를 별도 추출·연결했습니다. 보스룸의 연결된 벽과 아치는 접합부에서 분리했습니다.
