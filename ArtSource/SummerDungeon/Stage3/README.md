# Stage3 Summer — 기본 방 배치

씬: `Assets/Scenes/Stage3_Summer.unity`
에셋: `Assets/MapDesigne/Summer/`

## 방 구성
1. 해안 동굴: 38.4 × 36, 시작 X=0
2. 열대 숲: 38.4 × 36, 시작 X=44.4
3. 폭포: 38.4 × 36, 시작 X=88.8
4. 해안 절벽 보스 방: 46.08 × 43.2, 시작 X=133.2

크기는 바닥 배치 기준입니다. 현재 Stage4_Winter의 방 배치, 통로 간격 6, 확장된 크기와 20% 높아진 벽 높이를 기준으로 구성했습니다. 각 방 벽 높이는 대응하는 겨울 방의 모델 높이에 맞췄습니다. 암벽 부품은 연결 통로에 사용했습니다.

Hierarchy: `Summer_Rooms/Room_번호_컨셉` 아래 `Floor`, `Walls`, `Layout_Markers`. `Connections`는 방 사이 통로입니다. 마커는 보이지 않는 배치 기준점이며 보스 방에 `Boss_Spawn_Reserved`가 있습니다.

세부 장식, 추가 식생, 플레이어, 몬스터, 전투 진행, NavMesh와 방 스트리밍은 추가하지 않았습니다. 원본 모델 자체에 포함된 식생과 바위는 디자인 보존을 위해 유지했습니다. 폭포와 수면은 현재 정적 모델/텍스처입니다. 카메라는 전체 배치 확인용입니다.

## 에셋 최적화
- 원본 Summer_Tile_Designe.usdz는 유지했습니다.
- 벽 5종, 바닥 6종을 분리하고 원점·단위 크기를 정리했습니다.
- 총 삼각형: 11,070 → 10,518, 약 4.99% 감소.
- 원본부터 저밀도이며 잎과 돌 윤곽이 민감합니다. 암벽·열대 숲·폭포 벽은 감소 시 오차가 커 원래 삼각형 수를 유지했습니다.
- 원본 UV와 텍스처를 유지했습니다. 모든 프리팹은 공유 재질과 정적 MeshCollider를 연결했습니다.
- Blender에서 75/85/93/97% 유지 비율을 시험하고 원본과 최적화 메시의 꼭짓점→상대 표면 양방향 거리를 비교했습니다. 부품 최대 길이 대비 측정 오차 0.8% 이하만 채택했습니다. 이는 표본 측정이며 모든 표면 점의 수학적 오차 보장은 아닙니다.
- `../Optimization/Summer_Optimized.blend`: 원본/분리 모델 및 비교 렌더 설정.
- `../Optimization/Optimization_Report.json`: 부품별 수치.
- `../Optimization/Source_Review.png`, `Optimized_Review.png`: 동일 시점 비교 이미지.
