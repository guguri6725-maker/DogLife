# Stage1 탑 내부 숲 모델 레퍼런스

내장 image_gen으로 생성한 4×4 모델 시트입니다. VARCO3D 입력에는 필요한 모델 한 칸씩 잘라 사용하세요. 전체 시트는 제작 목록 및 스타일 참고용입니다.

01 거목 / 02 굽은 나무 / 03 갈라진 나무 / 04 쓰러진 나무다리
05 뿌리다리 / 06 수직 뿌리 발판 / 07 풀·흙 지형 / 08 이끼 석조 발판
09 큰 바위 / 10 작은 바위 / 11 덤불 / 12 늘어진 덩굴
13 풀 / 14 고사리 / 15 발광 버섯 / 16 뿌리에 잠긴 제단

이미지는 형태·색감 참고용이며 생성된 3D 모델의 충돌체, 폴리곤 수, 잎의 두께와 발판 상단 평탄도는 Unity·Blender에서 확인해야 합니다.

## 생성 프롬프트

전체 영문 생성 프롬프트는 prompt.txt에 기록했습니다. 통일된 반실사 스타일의 탑 내부 숲 모델 16종을 흰 배경의 독립된 칸에 정사영에 가까운 3/4 시점으로 배치하도록 지정했습니다.
