# 스킬창 검증

- Unity 플레이 모드에서 실제 EventSystem/PointerEventData 이벤트로 검사했습니다.
- 카드의 화면 좌표 레이캐스트가 카드를 선택하고 이름·상세 정보를 변경했습니다.
- 4개 슬롯 장착, 점유 슬롯 교환, 중복 스킬 이동, 슬롯 밖 드롭 취소, 우클릭 해제, 장착 스킬 선택을 통과했습니다.
- 4개 슬롯 중심의 레이캐스트가 각각 슬롯에 도달했습니다.
- ScrollRect 휠 이벤트로 목록이 이동하고 마지막 스킬까지 선택할 수 있었습니다.
- 닫기 버튼 이벤트가 게임 시간과 플레이어 입력을 복원했습니다. 다시 열면 장착 상태가 유지됩니다.
- 1920×1080 Game View 캡처로 레이아웃, 한글, 흰색 아이콘, 스크롤바를 확인했습니다.
- Inspector 참조 검사에서 누락 0개, 씬 검증에서 Missing Script / Broken Prefab 0개였습니다.

Windows 입력 도구는 `SetIsBorderRequired` 오류로 사용할 수 없어 실제 OS 키보드·마우스 주입은 검증하지 못했습니다. UI 이벤트와 창 상태 전환은 Unity 내부에서 검증했습니다.
