# Stage 1 — 3D Forest

- 씬: `Assets/Scenes/3D.unity`
- Hierarchy 루트: `Stage1_3D_Forest`
- 기존의 6개 일반 구간 → 보스 구간 흐름을 참고한 192 × 48m 숲 맵입니다.
- 카메라 기준 자유 이동과 3인칭 시점을 사용하는 3D 플레이 씬입니다.

## 파일

- `Models/`: 깊이를 복원하고 표면 음영을 다듬은 24개 모델과 숲 바닥 FBX.
- `Materials/`, `Textures/`: 3D 조명용 재질과 텍스처.
- `Forest3D.blend`: 개별 모델을 편집할 수 있는 블렌더 라이브러리.
- `.Source/ForestLayout.blend`: 전체 숲 배치를 편집하는 블렌더 원본. Unity가 전체 배치를 중복 임포트하지 않도록 숨김 폴더에 보관합니다.
- `Placements.json`: 최종 배치의 위치, 회전, 크기 기록.

## 구성

입구 숲 → 뿌리 테라스 → 바위 공터 → 무너진 신전 → 고사리 정원 → 거목 숲 → 보스 성소.
일반 구간마다 돌문과 옆길 발판을 두었으며, 외곽은 나무를 여러 겹으로 배치했습니다.
바닥과 주요 석조물에는 충돌체를 설정했습니다. 몬스터 17마리, 전투 게이트 7개, 회복 지점 2개와 출구를 배치하고 외곽 진입을 제한했습니다.

## 조작과 검증

- WASD 이동, 마우스 시점·조준, Space 점프, Shift 대시, Ctrl 또는 C 웅크리기.
- 왼쪽 클릭 공격, 1–4 무기 선택, R 탄환 속성 변경. 충전 검은 클릭을 누르고 있다가 놓습니다.
- Esc 마우스 잠금 전환, F5 현재 씬 다시 시작.
- 무기 4종, 지속 피해, 몬스터의 XZ 추적, 보스 원형 탄막, 회복과 7개 구간 완료를 플레이 모드에서 검사했습니다.
- 상세 측정 기록: `ArtSource/3DStage1/GameplayVerification.md`.

## 기존 자료 정리

Side View 전용 플레이어 표현과 TowerDungeon 장식, 기존 Stage01_Forest 씬을 제거했습니다. 재사용하는 리깅 모델은 `Assets/Art/Player3D`로 옮겼습니다. 기존 테스트·바다 씬과 제작·검증 도구는 삭제 승인 제한으로 `ArtSource/LegacyScenes`, `ArtSource/LegacyTools`에 텍스트로 보관합니다. Unity 실행 및 빌드 대상은 3D 씬입니다. 공용 무기·몬스터와 VARCO 원본은 유지합니다.

원본은 VARCO가 이미지 시트에서 재구성한 모델입니다. 02번 나무는 01번 나무의 변형이며, 일부 잎과 뒷면에는 원본 재구성 특유의 거친 형상이 남아 있습니다.
