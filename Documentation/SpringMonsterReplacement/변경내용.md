# 봄 몬스터 모델 교체 및 동작 확대

## 추가 동작 수정 — 2026-09-20

- 해골·사슴·토끼의 동적 관절 회전 폭을 기존보다 약 18~22% 확대했다. 사슴의 고정된 머리 방향 보정은 증폭하지 않았다.
- 정령의 걷기는 2.4초 주기의 부유 이동으로 새로 제작했다. 좌우 다리 교차, 골반 회전, 공격 시 발 고정 IK를 제거했다.
- 정령은 다리 방향을 유지하면서 몸통이 진행 방향으로 기울고, 양팔이 함께 넓은 곡선을 그린다. 공격 시 양손을 모았다가 앞으로 크게 뻗는다.
- NavMeshAgent와 충돌체의 위치는 유지하고 시각 모델의 Root 관절만 올린다. 기존 프리팹 크기에서 대기·이동 부유 오프셋은 약 18~26cm이며 공격·회피 시에는 더 올라간다.
- Unity에서 네 정령 클립의 허벅지·무릎 회전 변화량 0도, 이동 클립의 Root 오프셋 0.180~0.262m를 확인했다. 실제 Animator Walk 상태에서도 부유 오프셋이 적용되는지 검증했다.

- 기존 FBX와 색상·노멀 텍스처를 새 디자인으로 대체했다. 메타 GUID를 유지하여 방의 프리팹 참조를 보존했다.
- 관절 위치와 스킨 가중치를 새 체형에 맞추고, 인간형의 손·발 목표 자세를 새 팔·다리 길이에 맞춰 재생성했다.
- 해골 검의 공격 이펙트 궤적을 새 손·검 위치에서 다시 추출했다.
- 기존 몬스터 루트 크기, 전투 스크립트, 피해량과 공격 타이밍은 유지했다.

## 동작

- 해골: 보행 보폭·팔 흔들기와 공격 시 무릎·몸통의 준비/반동을 확대했다. 새 조형에 불필요한 이전 머리 회전 보정과 다리 모으기 보정은 제거했다.
- 사슴: 보행 다리 회전과 돌진 전 앞발 긁기 동작을 확대했다.
- 토끼: 이동 도약 높이, 웅크림, 앞·뒷다리 및 귀의 움직임을 확대했다.
- 정령: 보행 보폭·팔 흔들기, 대기 움직임과 후방 대시의 몸통·무릎 동작을 확대했다.

## 제작 파일과 검증

- `ArtSources/<몬스터>/Source.blend`: 제공된 새 디자인.
- `ArtSources/<몬스터>/<몬스터>_Rigged.blend`: 새 리깅과 애니메이션.
- `AnimationTemplate.blend`: 재생성용 뼈대·동작 템플릿. 이전 모델 메시/재질/텍스처는 포함하지 않는다.
- 이전 디자인의 프로젝트 제작 파일 및 해당 Blender 백업을 제거했다. 다운로드 폴더의 사용자 원본 파일은 수정하지 않았다.
- `Tools/replace_spring_monster_models.py`는 검토용 결과를 `Temp/MonsterReplacement`에 생성한다. 기존 개별 `build_*.py` 진입점도 새 제작 절차를 사용한다.
- Unity 반영 후 `DogLife.EditorTools.SpringMonsterModelRefresh.RefreshAll()`로 기존 클립·프리팹과 컬링 범위, 해골 이펙트 궤적을 갱신할 수 있다.
- 19개 클립 전체를 여러 시점에서 샘플링: 누락된 Transform 경로 0, NaN/Infinity 정점 0.
- 플레이 모드의 실제 방에서 무작위 소환과 Animator 재생을 확인했다. 검사 결과는 `UnityValidation.txt`에 기록했다.
