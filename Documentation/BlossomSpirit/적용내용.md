# Pink Floral Dryad 벚꽃 정령

사용자가 제공한 Pink Floral Dryad-801bd975b260b6eea2a0ca816e9e459d.fbx를 사용했습니다. Downloads 원본은 변경하지 않았습니다. 이전에 직접 생성한 모델은 사용하지 않습니다.

- 프리팹: Assets/Prefabs/monster/BlossomSpirit.prefab
- 탄환: Assets/Prefabs/monster/BlossomPetalProjectile.prefab
- Unity 임포트 메시: **30,000 삼각형**, 원본 리그 **23개 뼈**. 외형과 포함된 색상/노멀 텍스처를 유지했습니다.
- Blender 작업 파일: ArtSources/BlossomSpirit/PinkFloralDryad_Animated.blend
- 애니메이션: Idle 2.4초, Walk 1.2초, Attack 1.8초. Idle/Walk 반복, Attack 1회. 양손 모으기 → 조준 → 앞으로 내밀어 발사 → 복귀입니다.
- 원본 모델의 손 위 장식 꽃잎도 유지했습니다. 옷자락 일부에는 원본 팔 가중치가 포함되어 시전 시 함께 움직입니다. 강제로 분리했을 때 경계가 늘어나 최종본은 원본 가중치를 유지했습니다.
- 공격: 4m 이내에서 후퇴, 약 6m 거리 유지, 9m 이내에서 시전. 0.9초에 조준 고정, 1.22초에 꽃잎 탄환 1발, 시전 후 1.3초 쿨타임. 탄환 속도 5m/s, 피해 4, 최대 비행거리 12m. 체력 22.
- 양손 꽃잎 파티클과 분홍색 꽃잎 탄환/잔상을 연결했습니다. 탄환은 직선으로 날아가며 기존 CombatProjectile 충돌 판정을 사용합니다.
- 기존 StageEnemy, CombatHealth, CombatProjectile 스크립트는 수정하지 않았습니다. 전용 BlossomSpiritEnemy를 사용합니다. 기존 씬에는 배치하지 않았습니다.

## 검증

Unity에서 앞/옆 시전 자세와 이펙트를 렌더링했습니다. SpiritEffects.png를 참고하세요. 원본 가중치에 따른 옷자락 움직임도 포함되어 있습니다.

격리된 프리팹 검사에서 양손 파티클 표시, 반복 발사 처리 시 1발만 생성, 조준점 고정, 벽에 가려지면 발사하지 않음, 쿨타임, 대상 사망 시 시전 취소를 확인했습니다. 세 클립의 뼈 경로 누락은 0입니다. 자세별로 모델이 잘리지 않도록 bounds를 갱신했습니다. 상세 결과는 Verification.txt입니다.

실제 스테이지에서 이동/후퇴와 피격을 직접 조작하는 검증은 하지 않았습니다. 사용할 씬의 NavMesh가 필요합니다.
