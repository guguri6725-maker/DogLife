# 가을 스테이지 제작

- 작업 씬: `Assets/Scenes/Stage3_Fall.unity`
- 최종 구성은 9개 메인 방입니다. `Assets/Scenes/SeasonRooms/AutumnJourney9`의 방 씬을 순서대로 연결했습니다.
- 봄의 바닥·돌벽 재질은 유지하고, 모서리를 잘라낸 비대칭 외곽과 가을 전용 단풍나무·고목·쓰러진 나무·폐허 배치를 새로 만들었습니다.
- 1~3번: 초가을 숲길, 황금빛 굽이, 쓰러진 나무가 있는 통로.
- 4~6번: 호박빛 폐허, 수확 시장 옆 숲, 구리빛 뿌리 숲.
- 7~9번: 붉은 합성 작업장 옆 숲, 진홍빛 수림, 고목과 낙엽이 쌓인 늦가을 성역.
- 진행 방향(+X) 기준 5번째 방 왼쪽(+Z)에 상점, 7번째 오른쪽(-Z)에 합성방을 붙였습니다. 메인 방을 클리어하면 옆문도 열립니다.
- 상점에는 천막·진열대·상자, 합성방에는 작업대·호박색 결정과 코어를 배치했습니다. 이번 범위는 공간 제작이며 구매/합성 상호작용 시스템은 추가하지 않았습니다.
- 후반으로 갈수록 단풍은 노랑→주황→진홍→적갈색으로 짙어지고, 지면 낙엽도 늘어납니다. 마지막 방은 일부 수관이 성긴 늦가을 고목을 강조했습니다.
- 중앙 전투 공간과 입출구를 확보하고, 방별 장애물에 맞게 독립적인 내비게이션 데이터를 베이크했습니다.
- 기존 현재 방·다음 방 스트리밍 및 방당 몬스터 3마리 생성 방식을 사용합니다. 몬스터 종류는 기존 봄 몬스터를 재사용합니다.
- 봄 씬과 원본 봄 재질은 수정하지 않았습니다. 새 메시·재질은 `Assets/Art/AutumnJourney9`에 있습니다.
- 편집기 생성 도구: `AutumnNineRoomBuilder.Build(0..8)` 및 `Connect()`. Build는 해당 생성 방을 다시 만들므로 수동 편집 후 실행하지 마세요.
- 9개 방 연속 전환, 각 방 몬스터 3마리 생성, 양쪽 부속방의 완전한 내비게이션 경로를 확인했습니다.
- 타이틀 진입 경로와 배포 빌드는 변경하지 않았습니다.

## 입구 개방 수정

- 다음 방 입구의 `startOpen` 변경이 프리팹 오버라이드에 저장되지 않아, 현재 방 출구만 열리던 문제를 수정했습니다.
- 2~9번째 방 입구를 처음부터 열린 상태로 저장하고, 생성 도구도 문 컴포넌트의 프리팹 변경을 명시적으로 기록하도록 수정했습니다.
- 입장 후 뒷문을 닫는 기존 스트리밍 동작은 유지합니다.
- `VineGate.Update`의 근사 비교 조기 종료 때문에 개방 진행도가 0.9999997에 멈추고 충돌이 남던 문제도 수정했습니다. `MoveTowards`가 정확한 끝값까지 도달하도록 했습니다.
