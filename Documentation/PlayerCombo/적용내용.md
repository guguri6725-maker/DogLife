# 기본 5단 콤보 / 기존 무기 제거

## 최종 상태
- 총(Rifle), 샷건(Shotgun), 검(Sword), 차징 무기(ChargeSword)의 데이터 4개, 프리팹 4개, 전용 머티리얼 4개와 WeaponDefinition 스크립트 삭제. 각 meta도 삭제.
- 삭제 전 외부 자산의 참조가 없음을 확인. 기존 무기 교체, 탄종 변경, 연사/차지 입력과 안내 UI 제거.
- PlayerWeapons는 기본 근접 공격/조준을 담당. 피해 3, 사거리 2는 Inspector에서 조정 가능. 적이 사용하는 공통 발사체 생성 함수는 유지.
- 공격 시작 시 정면 방향 고정. 마우스를 움직여도 공격 중에는 캐릭터 방향이 바뀌지 않음.
- 생성한 5개 공격 클립의 골반 수평 회전과 루트/골반 수평 이동을 보정. 원본 Sword_Attack은 유지.
- 공격 모션 중 이동/대시/점프/웅크리기 차단. 시작 전 남은 대시와 점프 예약 제거. 중력과 적의 넉백은 유지.
- 공격 종료/취소 시 이동 재개. 기존 클릭 콤보 입력 시간과 9방향 이동 유지.

## 수정 코드
- PlayerWeapons.cs: 기존 무기 분기 제거, 기본 근접 판정과 공격 중 조준 잠금.
- PlayerAttackCombo.cs: 공격 중 상태 공개, 공격 시작 시 이동 정지 호출.
- PlayerMotor.cs: 공격 상태 기반 이동/대시/점프/방향 잠금 및 속도 정리.
- PlayerAttackComboBuilder.cs: 공격 클립 정면 보정과 수평 이동 제거.
- PrototypeHUD.cs: 삭제한 무기/차지/탄종 안내 제거.
- Player/SeasonGameplay 프리팹과 기본 공격 클립 재저장, 3D 씬의 제거된 직렬화 필드 정리.

## 검증
- 공격 중 수평 속도 0, 대시 거부, 점프 예약 0.
- 방향 변경 요청에도 정면 유지.
- 1~5타 모두 이동 잠금 유지.
- 종료 후 이동 속도 4로 복구.
- 삭제 무기 참조 검색 결과 0, 콘솔 오류 0.
- MovementLockVerification.txt 및 ForwardPoses.png 참고.
