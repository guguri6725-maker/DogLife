# 봄 몬스터 4종 검토

Unity Play Mode의 격리된 평면 NavMesh에서 현재 저장된 프리팹 4종을 대상으로 공격 상태와 렌더링 프레임을 확인했습니다. 테스트 사본만 사용했고 원본 프리팹과 씬은 수정하지 않았습니다. 실제 봄 맵의 지형·다수 몬스터 전투 밸런스를 모두 검증한 결과는 아닙니다.

## 1. 뼈 사슴: 기능 문제, 우선 수정 필요
현재 프리팹 루트 Scale은 (2,2,2)입니다. NavMeshAgent의 실제 중심 높이는 바닥 위 2m가 되지만 TickCharge는 baseOffset 1m만 빼고 반경 0.8m로 바닥을 찾습니다. 결과적으로 바닥 탐색이 실패하고 돌진 직후 Recover로 전환됩니다. 현재 크기에서는 이동 0m, 대상 피해 0이 재현됐습니다.

테스트 사본의 루트 크기를 1로 바꾼 대조 실험에서는 동일 경로로 7m 돌진하고 피해 7을 적용했습니다. 크기를 유지하려면 바닥·경고선·공격 판정 계산에서 월드 크기를 일관되게 처리해야 합니다. 준비 중 앞발 긁기와 몸의 체중 이동도 작아 시각적으로 약합니다.

## 2. 벚꽃 정령: 장식 변형
양팔을 모으는 동안 허리·치마의 꽃잎 장식이 팔과 함께 끌려 올라갑니다. 의도한 천 움직임보다는 스킨 가중치가 팔에 과하게 연결된 모습입니다. 장식 가중치를 골반·몸통으로 분리하는 것이 우선입니다. 발사 자세와 대기 자세 변화도 상체 위주라 하체가 경직돼 보입니다.

현재 크기 2배 상태에서도 player로 표시한 테스트 대상에게 투사체 피해는 확인했습니다. 첫 기록의 대상은 player=false였으므로 그때의 피해 0은 공격 실패 근거로 사용하지 않습니다.

## 3. 벚꽃 해골: 무게감과 이펙트
검을 머리 위로 올리고 아래로 내려치는 순서는 재생됩니다. 다만 허리·무릎·골반의 움직임이 작아 상체와 팔만 움직이는 느낌이 강합니다. 검의 분홍색 궤적은 넓고 각진 띠로 보여 꽃잎 베기보다 부채 같은 면으로 읽힙니다. 띠 폭과 투명도, 가장자리 소멸을 다듬는 것이 좋습니다.

현재 루트 Scale이 2배이지만 공격 거리 등은 고정 월드 수치입니다. 첫 테스트에서 공격 중 1.5m 전진한 기록이 있습니다. 이는 별도 프레임 검증이 더 필요하며 의도된 돌진으로 확정하지 않았습니다. 다른 대상 높이에서도 접근 거리와 실제 칼끝 위치가 일치하는지 추가 확인이 필요합니다.

## 4. 꽃토끼: 상대적으로 양호, 동작 연결 개선
웅크림 → 점프 → 착지 피해 → 후퇴 순서는 정상입니다. 착지 피해 5를 확인했습니다. 다른 3종과 달리 루트 크기는 1입니다.

다만 점프 중 다리 자세 변화와 착지 반동이 작고, 후퇴 때 몸 방향을 유지하면서 평행 이동하는 느낌이 있습니다. 회전도 즉시 바뀌어 주변 이동으로 복귀할 때 방향이 튀어 보입니다. 발 접지와 후퇴 홉, 짧은 회전 보간을 다듬으면 개선될 것으로 판단합니다.

## 검증 파일
- 각 몬스터 PNG: 0.25초 간격 실행 프레임, 왼쪽에서 오른쪽·위에서 아래 순서. 카메라가 몬스터를 따라가므로 이동 거리는 Runtime.txt를 함께 참고해야 합니다.
- Runtime.txt: 현재 프리팹 상태 기록.
- DeerRetest.txt: 현재 크기에서 돌진 즉시 종료 재현.
- ScaleComparison.txt: 테스트 사본 크기 1에서 7m 돌진 및 피해 확인.

콘솔 오류는 발견되지 않았고 테스트 종료 후 편집 모드로 복귀했습니다. 우선순위는 사슴 기능 문제 → 정령 가중치 → 해골 무게감/이펙트 → 토끼 동작 연결입니다.
