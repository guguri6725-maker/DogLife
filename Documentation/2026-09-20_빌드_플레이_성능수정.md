# Windows 빌드 플레이 성능 수정

## 확인한 문제

- 기존 바탕화면 빌드의 Player.log에서 Direct3D 12의 vsync/시간 측정 이상 메시지와 non-legacy 문 애니메이션 SampleAnimation 오류 확인.
- 봄 첫 방의 동일 시점 에디터 A/B 측정: 기존 Ultra 설정 평균 draw calls 2641, triangles 318만, shadow casters 1686. 그림자 거리 45m/2 cascade, LOD bias 1 적용 후 1691 / 152만 / 737. 에디터 수치이며 실행 빌드의 개선율을 의미하지 않음.

## 변경

- Windows 그래픽 API 기본 순서 Direct3D11 → Direct3D12.
- FPS 설정창에서 60/120/144/165/240/제한 없음을 선택하고 자동 저장. 처음 실행 시 모니터 주사율에 맞는 제한을 선택하며, vsync 대신 선택한 목표 FPS 적용. 아래 성능 수치는 설정창 추가 전 60 FPS 제한으로 측정한 결과.
- 기본 Ultra 품질의 그림자 거리 150→45m, cascade 4→2, LOD bias 2→1. 가까운 모델 원본은 유지되며 멀리 있는 모델은 더 빨리 기존 LOD로 전환됨.
- CombatHealth는 피격 섬광 상태가 바뀔 때만 Renderer 속성을 갱신.
- PlayerWeapons 조준은 재사용 Raycast 버퍼에서 최근접 충돌을 찾음. 버퍼가 가득 차면 전체 조회로 대체해 조준 정확도 유지.
- VineGate의 non-legacy 클립은 수동 PlayableGraph로 평가해 실행 빌드에서도 문 애니메이션이 작동하도록 수정.
- 기존 StageEnemy 및 처치 후 다음 방을 생성하는 규칙은 유지.

## 실행 검증

- 별도 Release 테스트 빌드(1920×1080, RTX 4060 Ti, Direct3D11)를 자동 실행해 봄 1·2번 방에서 이동·카메라 회전·공격을 수행하고 방 사이 전환 확인.
- 각 방 15초 중 처음 2초를 제외한 780프레임 측정. 1번 방 median/p95 16.67ms, 최대 17.36ms. 2번 방 median/p95 16.67ms, 최대 16.79ms. 두 구간 모두 33.3ms 초과 0회.
- 자동 실행 인자 -doglife-performance-check를 줄 때만 검사 코드가 동작하며, 일반 실행에는 영향 없음. 자동 테스트는 수동 플레이의 모든 전투/이펙트 조합을 보장하지 않음.
- 기존 Player.log의 애니메이션 오류와 vsync 이상 메시지는 테스트 빌드 로그에서 재발하지 않음.
- 빌드 목록에 남아 있던 삭제된 3D/ForestRooms 씬 8개를 제외하고, 현재 존재하는 타이틀·사계절 스테이지·방 43개를 포함해 기존 Desktop/DogLife_Window/DogLife.exe 덮어쓰기 완료. 빌드 성공, 866.64MB, 오류 0, 향후 메시 임포트 호환성 경고 2개.
- 덮어쓴 최종 실행 파일도 자동 검증 완료: 두 방 각각 780프레임, median/p95 16.67ms, 최대 16.81 / 16.75ms, 33.3ms 초과 0회. 전환 성공 및 로그에 예외/문 애니메이션 오류/vsync 이상 없음. 자동 검증 종료 후 게임 프로세스는 종료된 상태.
