# 화면·그래픽 설정 (2026-09-21)

- Esc/오른쪽 위 설정 버튼. 좌우 화살표로 선택하고 적용. 닫기는 미적용 선택 취소.
- 모니터(연결 목록), 해상도(모니터 크기 내 표준 해상도 및 네이티브), 창/테두리 없는 전체화면/전체화면.
- 낮음/보통/높음: 프로젝트 품질 단계와 그림자 거리 20/35/45m, LOD bias 0.6/0.85/1, AA 0/2/4.
- FPS 60/120/144/165/240/제한 없음. 수직 동기화 사용 시 FPS 제한은 비활성화되며 주사율 동기화 우선.
- 3D 렌더링 50/67/75/85/100%. 기본 렌더러용 축소 카메라 패스로 월드를 렌더링하고 HUD/인벤토리/설정은 원래 화면 해상도로 표시. 100%에서는 축소 패스 비활성화.
- 첫 실행은 최대 1080p 창, 보통 품질, 렌더링 100%, 60 FPS. 기존 FPS 선택은 유지. 하드웨어 벤치마크 기반 자동 추천은 아님.
- 화면 변경은 15초 확인 후에만 저장. 되돌리기/Esc/시간 초과로 이전 설정 복원. 프로세스 종료 시 미확정 설정은 다음 실행에 사용하지 않음.
- 설정은 PlayerPrefs의 DogLife.Graphics.v1에 저장. 모니터가 없으면 현재 목록 첫 모니터와 적합한 해상도로 복구.
- GameSettingsWindow, PlayerFramePacing, GameSettingsBuilder 변경. GameGraphicsSettings 및 WorldRenderScale 추가. 몬스터와 전투 스크립트는 이번 작업에서 수정하지 않음.

## 검증
- 에디터 컴파일 오류 없음. 타이틀·봄 설정 화면 확인.
- 수직 동기화 켜짐에서 vSyncCount=1 / targetFrameRate=-1, 끔에서 선택 FPS 재적용.
- 15초 자동 복원, 설정 저장, 게임 일시정지/복귀 확인.
- 1080p에서 50% 적용 시 내부 렌더 텍스처 960x540, HUD 출력 유지, 메인 카메라 targetTexture 없음, 중앙 조준 방향 오차 약 0.028도(픽셀 중심).
- 품질 3단계의 그림자 거리와 LOD 설정 반영 확인.

- Windows 빌드 성공(오류 0). 실제 실행에서 ZOWIE 240Hz → DP 60Hz 이동, 확인창 표시, Esc로 ZOWIE 복원 확인. 기존 DogLife.exe 덮어쓰기 완료.
