# 무기 ScriptableObject 데이터

출처: 구동찬게임기획.pptx, 7~12쪽.

Assets/Data/Weapons 아래 Human / Dog 각각 Basic / Synthesized 폴더에 6종씩, 총 24개 InventoryWeapon 에셋을 생성했습니다. WeaponCatalog.asset에서 전체 목록을 확인할 수 있습니다.

| 무기 | 뼈 | 일반형 공격력 |
|---|---|---:|
| 칼 | 경골 | 22 |
| 창 | 비골 | 26 |
| 도끼 | 견갑골 | 38 |
| 활 | 갈비뼈 | 18 |
| 단검 | 요골 | 11 |
| 부메랑 | 쇄골 | 15 + 귀환 15 |

- 인간뼈 일반형: 일반 적/보스 막타 +1/+1. 합성형: +5/+15.
- 강아지뼈 일반형: -1/-1. 합성형: -5/-15.
- 합성형 이름은 인간뼈 ‘증오의’, 강아지뼈 ‘영혼의’ 접두어 사용.
- 일반형의 Same Weapon Evolution에 동일 계열/종류 합성형을 연결.
- 합성형 공격력, 모든 무기의 사거리와 공격 간격은 미정. Defined 체크가 꺼져 있고 0은 미정 자리표시입니다. UI에는 0 대신 미정으로 표시합니다.
- 모델과 아이콘은 비워 뒀습니다. 인벤토리 보유 목록/드롭 테이블에는 추가하지 않았습니다.
- 이번 작업은 데이터 생성입니다. 활/부메랑 등 개별 공격, 귀환 피해, 카르마 적용, 합성 실행 시스템을 구현한 것은 아닙니다.

변경: InventoryWeapon.cs(분류/상태/카르마/진화 참조), WeaponCatalog.cs(신규), SkillWindow.cs(계열/형태/미정 스탯 표시).
검증: 조합·ID 중복 없음, 24개 수량, 일반형 공격력 12개, 진화 참조 12개, 카르마 및 미정 플래그 확인. Unity 컴파일 오류 없음.
