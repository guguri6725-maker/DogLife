# K키 인벤토리 전환

- 기존 스킬창을 보유 무기 8칸 / 장착 무기 1칸 인벤토리로 전환.
- K 열기/닫기, Esc 또는 X 닫기. 창이 열리면 게임 일시정지, 이동/공격/시점 입력 차단. 닫을 때 원상 복구.
- 무기 선택 후 장착 버튼, 목록에서 장착 슬롯으로 드래그 지원.
- 장착 해제 버튼, 슬롯 우클릭, 슬롯에서 목록으로 드래그 지원.
- 현재 인벤토리는 비어 있음. 삭제한 기존 무기나 테스트 무기는 저장하지 않음.
- 장착 시 아이템의 피해량/사거리/외형을 사용하고, 해제 시 맨손 기본 수치와 5단 콤보를 사용.
- Hierarchy: SeasonGameplay / InventoryUI / InventoryWindow.
- 새 무기 데이터는 Create > DogLife > Inventory Weapon으로 생성하고 PlayerInventory의 Owned Weapons에 연결 가능. 런타임 획득은 AddWeapon 사용. 소유하지 않은 무기는 장착 불가.
- 현재 인벤토리는 실행 세션 단위이며 별도 저장/로드는 포함하지 않음.

## 코드
- 신규: InventoryWeapon.cs, PlayerInventory.cs, InventoryDropArea.cs.
- 수정: SkillWindow.cs, SkillCard.cs, PlayerWeapons.cs. 기존 입력 차단 참조 호환을 위해 SkillWindow 클래스명은 유지.
- 프리팹: Player 및 SeasonGameplay. UI 버튼/슬롯은 Hierarchy에 저장.

장착/교체/드래그/우클릭/버튼 해제와 일시정지 복구를 플레이 모드에서 확인. Verification.txt 참고.

## 3열 배치 추가
- 기존 색/서체/패널 디자인 유지. 좌측 보유 무기, 중앙 캐릭터 3D 미리보기와 장착 무기, 우측 선택 무기 특징/스탯.
- InventoryWeapon에 Bone Name(뼈 종류), Bone Origin(인간형/동물형) 추가. 공격력/범위는 실제 장비 데이터 표시.
- InventoryCharacterPreview가 별도 모델/카메라로 표시하며 장착/해제 때 무기 외형 갱신. 선택만 바꿔도 실제 장비는 바뀌지 않음.
- 창을 닫으면 미리보기 모델과 렌더 텍스처 해제.
- 테스트 무기는 저장하지 않음. ThreeColumnVerification.txt / ThreeColumn.png 참고.
