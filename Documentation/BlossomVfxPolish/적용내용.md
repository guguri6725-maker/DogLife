# 벚꽃 몬스터 공격 이펙트 개선

- 벚꽃 정령: 양손 꽃잎의 회전·응집, 색상/투명도 변화와 탄환의 회전 꽃잎 및 잔상 개선.
- 꽃토끼: 점프 꽃잎 밀도와 잔상 조정. 착지 시 32장의 꽃잎이 위/바깥쪽으로 퍼지며 사라짐.
- 토끼 착지 표시: 반투명 원형 바탕, 벚꽃 문양, 점선 안쪽 원과 차오르는 진행 표시.
- 사슴 돌진 표시: 반투명 통로, 진행 방향 화살표, 벚꽃 문양. 기존 판정 경계선 유지.
- 기존 LineRenderer 좌표로 장식 메시를 생성하므로 기존 범위와 위치를 따름.
- 플레이 모드에서 표시 활성화/종료, 파티클 생성/정리 확인. 콘솔 오류 0건.
- Telegraphs.png는 범위 표시만 분리한 미리보기. Verification.txt는 확인 결과.
