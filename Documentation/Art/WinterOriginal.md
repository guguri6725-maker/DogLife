# 겨울맵 신규 제작 — 2026-09-22

## 적용 내용

- 기존 모델을 변형한 WinterPolish 시안을 새로 만든 WinterOriginal 메시로 교체했습니다.
- Blender에서 정점·면으로 제작한 43종: 벽 5종, 바닥 5종, 자연 구조물 31종, 상점 가판대와 합성 화로 2종입니다.
- 기존 FBX는 새 메시 생성에 불러오지 않았습니다. 기존 크기와 배치만 참고했습니다.
- 직접 생성한 1024×1024 반복 텍스처 5세트(눈, 층상 암석, 얼음, 수피, 침엽수)에 각각 색상과 노멀 맵을 적용했습니다.
- 문은 기존 모델과 애니메이션을 유지하고 새 얼음 텍스처를 적용했습니다.
- 게임 진행은 11개 주 방입니다. 7번째 왼쪽에 상점, 9번째 오른쪽에 합성방을 배치했습니다. 왼쪽은 +X 진행 방향 기준 +Z입니다.
- 예전 5·8번째 방 내부 시설을 옆방으로 옮기고, 비어 있던 두 방에는 기존 몬스터 풀을 Inspector로 연결했습니다.
- 바닥 중복을 정리하고 새 충돌 메시로 교체했으며 11개 방의 NavMesh를 새 에셋으로 베이크했습니다.
- 예전 길이에 머물러 있던 스테이지 외곽 경계도 11개 방에 맞췄습니다.
- 제외한 이전 11·12번째 방 씬은 원본 파일로 남겼습니다. 실제 진행 목록에서는 제외됩니다.

## 검증

- 11개 방의 순번, 씬 빌드 등록, 몬스터 프리팹 참조와 새 NavMesh 저장을 확인했습니다.
- 모든 방의 입구→출구와 상점·합성방 진입 경로가 PathComplete였습니다.

- 문 열림 완료(Progress=1) 후 통과 콜라이더 비활성 확인.
- 활성 환경 렌더러의 재질은 모두 WinterOriginal이며 문 재질만 기존 에셋을 새 텍스처로 수정했습니다.
- 전체 11개 방을 직접 조작하여 전투 클리어하는 검증까지 수행한 것은 아닙니다.
