# 겨울 맵 구조물·통로·텍스처 수정

## 추가 수정: 상점·합성방 옆문

- 상점 문에는 씬 개별 참조가 남아 원본의 열린 프레임 메시를 계속 사용하고 있었습니다. 양쪽 MeshFilter와 MeshCollider를 폐쇄 수정본으로 직접 연결했습니다.
- 상점·합성방 문 너비 배율을 0.70에서 0.85로 조정했습니다. 문틀과 보조방 앞벽은 양쪽 약 0.70m 겹쳐 연결됩니다.
- 플레이 모드에서 문을 연 뒤 본방·보조방 양방향의 문틀을 촬영해 빈틈을 확인했습니다. 변경은 두 방 씬에 저장했습니다.

## 추가 수정: 벽 모서리 틈

- 첫 방 끝벽의 끝과 옆벽 사이에 약 0.76m의 빈 구간이 남아 있었습니다.
- 11개 방의 끝벽 42개를 Hierarchy에서 연장하고 바깥 방향으로 이동했습니다. 안쪽 끝 위치는 유지해 문 통로 폭을 보존했습니다.
- 44개 모서리 연결을 검사했고, 끝벽이 옆벽 중심을 최소 0.45m 지나도록 연결돼 있습니다. 보스방 입구 두 곳은 기존 길이가 충분했습니다.
- 첫 방 해당 모서리를 근접 촬영해 빈틈이 닫힌 것을 확인했습니다. 변경된 충돌 형상에 맞춰 방별 NavMesh도 재베이크했습니다.

## 수정 내용

- 문 좌우 프레임 원본에 열린 경계가 각각 364개·339개 있었습니다. Blender에서 구멍을 막고 면 방향을 정리한 폐쇄 메시로 교체했습니다. 화면용 메시와 MeshCollider 모두 같은 수정본을 사용합니다. 기존 문 열림 애니메이션은 유지했습니다.
- RockRamp의 쐐기 본체 면 방향이 뒤집혀 있었습니다. 모든 본체 면 방향을 바로잡고 충돌 메시도 새로 저장했습니다. 위쪽에서 검사했을 때 두 경사면 모두 충돌하며 위쪽 법선이 약 0.82로 확인됐습니다.
- 11개 방의 큰 구조물 크기를 조정하고 간격을 확보했습니다. 서로 다른 구조물의 LOD0 수평 경계 상자가 겹치는 사례는 수정 후 0건입니다. 중앙 통로, 문 앞, 7번 방 왼쪽 상점과 9번 방 오른쪽 합성방 연결 통로를 비웠습니다.
- 11개 방의 NavMesh를 다시 베이크하고 씬을 저장했습니다.
- 내장 imagegen으로 돌과 얼음 텍스처를 새로 제작했습니다. 돌은 차가운 회색 암석, 얼음은 불규칙한 가는 균열로 구성했습니다. 월드 좌표 기반 매핑으로 벽·돌·얼음·문의 텍스처 늘어짐을 줄였습니다.

## 검증과 범위

- 11개 방 입구→출구 NavMesh 경로: 모두 PathComplete.
- 상점·합성방 연결 경로: 모두 PathComplete.
- 플레이 모드에서 반지름 0.5 캡슐로 검사한 11개 중앙 통로: 막힘 없음.
- 첫 방 스트리밍 완료, LoadError 없음, 확인 시 콘솔 오류 없음.
- 수정 셰이더 컴파일 오류 없음. 문 옆면·경사 구조물 화면 확인 완료.
- 전체 방을 직접 조작해 모든 틈을 통과하거나 전투를 클리어한 검증은 아닙니다. 구조물 내부에서 의도적으로 결합한 개별 부품은 서로 다른 구조물 간 겹침 검사 대상이 아닙니다.
