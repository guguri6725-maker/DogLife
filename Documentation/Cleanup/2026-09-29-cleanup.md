## 스크립트 변경

### 단일 관리자 수명 정리

- `SkillWindow.Instance`: 현재 게임 씬의 인벤토리 관리자입니다. `IsOpen`은 별도의 정적 bool을 복제하지 않고 해당 인스턴스의 상태를 읽습니다. 중복 컴포넌트의 입력 처리를 차단하고 종료 시 참조·이벤트를 정리합니다.
- `ForestRoomStreaming.Instance`: 계절 씬 안에서 방 씬들이 공유합니다. 씬 종료 시 참조를 해제하며 `DontDestroyOnLoad`로 남기지 않습니다. `ForestRoom`의 전체 씬 검색을 이 참조로 대체했습니다.
- `GameSettingsWindow.Instance`: 기존 영속 싱글톤을 공개하여 타이틀의 설정창 검색을 제거했습니다. 렌더링 해상도 컴포넌트는 카메라 변경 시에만 다시 찾습니다.
- 정적 인스턴스는 플레이 초기화 시 리셋합니다. 중복 인스턴스가 생기면 경고 후 해당 관리자 컴포넌트를 비활성화합니다.
- 여러 개를 사용하는 플레이어 구성 요소, 적, 체력, 공격 이펙트는 싱글톤으로 바꾸지 않았습니다. 기존 Inspector 참조와 버튼 연결을 유지했습니다.

### 공통 정리

- `StageOneDirector.EndRun()`: 반복되는 적 비활성화·위험 오브젝트 제거 코드를 공통 함수로 묶었습니다. 사망과 클리어 호출이 겹쳐도 종료 처리를 한 번만 수행합니다.
- 기존 피아누스 프로토타입 전용 `SeaBoss`/`SeaHazard`와 해당 정리·카르마 분기를 제거했습니다. 현재 여름 보스인 `KrakenBoss`는 유지했습니다.

## 에셋 삭제 기준

1. Unity `AssetDatabase.GetDependencies`로 프로젝트 에셋 2,235개의 참조를 확인했습니다.
2. 씬·프리팹뿐 아니라 모델 임포터 `.meta`, 프로젝트 설정의 GUID 참조를 합쳐 검사했습니다.
3. 스크립트·Tools의 경로 문자열과 폴더 경로를 이어 붙여 사용하는 제작 도구를 확인했습니다.
4. 남는 에셋에서 참조하지 않는 프리팹·머티리얼·메시·NavMesh만 삭제했습니다. 삭제되는 프리팹의 전용 재질도 함께 정리했습니다.
5. 모든 삭제 파일이 기준 Git 커밋에 존재하고, 감사 이후 내용이 바뀌지 않았는지 SHA-256으로 확인했습니다.

`Resources`, `VARCO3DImports`, 플러그인, 게임 데이터, 모델 FBX와 애니메이션·텍스처 제작 원본, 테스트 씬은 유지했습니다. 미참조라는 이유만으로 제작용 원본을 삭제하지 않았습니다. 전체 삭제 경로·GUID·크기·SHA-256은 [삭제 목록](2026-09-29-removed-assets.json)에 있습니다.
