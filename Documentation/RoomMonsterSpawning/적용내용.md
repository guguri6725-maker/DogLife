# 방별 랜덤 몬스터 배치

- 기존 몬스터가 있던 필드마다 방 로딩 시 새 봄 몬스터 4종 중 정확히 3마리를 준비합니다.
- 해골·벚꽃 정령·뼈 사슴·꽃토끼를 무작위 선택하며 세 마리가 전부 같은 종류인 조합은 금지합니다. 두 마리의 종류가 같은 조합은 허용합니다.
- 방 로딩과 스폰 위치 검증이 끝나면 즉시 세 마리를 활성화합니다. 다음 방도 입장을 기다리지 않고 로딩 완료 즉시 소환됩니다. 입장 시 다시 생성하지 않습니다.
- 길찾기 바닥, 방 경계, 장애물과 3.5m 간격을 확인한 후 생성합니다. 준비 실패는 로딩 오류로 처리하여 빈 방이 자동 클리어되지 않게 합니다.
- 몬스터의 현재 크기와 NavMeshAgent 높이 보정을 유지합니다.
- 새로운 4종도 플레이어 사망 또는 스테이지 종료 시 정지합니다.

## 적용 범위
다른 계절의 임시 Wood도 함께 교체하는 기본안으로 적용했습니다. 계절 필드 32개와 구형 ForestRooms 7개, 총 39개 씬의 기존 몬스터 배치를 교체했습니다. 원래 몬스터가 없던 상점 등에는 새로 추가하지 않았습니다. 봄 합성 방은 기존에 전투가 있었으므로 필드 전투를 유지합니다.

## 삭제
Wood, SeasonTestWood, Mushroom, ForestSpirit, ForestGuardian 프리팹과 사용되지 않는 전용 모델·애니메이션·컨트롤러, Mushroom red/Spirit purple 재질을 삭제했습니다. 삭제 전 남은 에셋의 의존성이 없음을 확인했습니다. 공용 StageEnemy와 다른 곳에서 사용하는 공용 재질은 유지했습니다.

기존 Mushroom 프리팹을 템플릿으로 사용하던 새 몬스터 제작 도구는 독립 루트 생성 방식으로 변경했습니다.

## 검증
- 랜덤 조합 10,000회: 3마리 동일 종류 발생 0회.
- 계절 필드 32개 실제 비동기 로딩: 전부 준비 성공, 3마리, 최소 2종.
- 봄 첫 방: 크기에 맞는 높이와 NavMesh 연결 확인.
- 첫 방 전원 처치 → 다음 방 3마리 비활성 준비 → 입장 시 활성 → 이전 방 해제 확인.
- 콘솔 오류 없음. 편집 모드로 복귀.

Migration.txt는 변경 씬 목록, DeletionCandidates.txt는 삭제한 모델/프리팹 목록(추가 재질 2개 제외), Verification.txt와 AllSeasonRooms.txt는 실행 검사 결과입니다. 구형 ForestRooms 7개는 참조 교체를 확인했으며 이번 전수 로딩 검사는 계절 필드 32개를 대상으로 했습니다.
