## 애니메이션

| 클립 | 길이 | 용도 |
|---|---:|---|
| Idle | 2.4초 | 목과 꼬리의 대기 움직임, 반복 |
| Walk | 1초 | 네 다리 보행, 반복 |
| Windup | 1.35초 | 앞발로 바닥 긁기 후 고개 숙이기 |
| Charge | 0.5초 | 숙인 고개 유지 및 빠른 달리기, 반복 |
| Recover | 1초 | 정지 후 고개를 들며 복귀 |

Root Motion은 끄고 전용 FloralDeerEnemy가 실제 이동을 담당합니다. 전투 상태에 맞춰 Animator의 클립을 전환합니다. 모든 자세를 포함하는 스킨 bounds를 설정했습니다.

## 공격과 효과

감지 거리 14m, 공격 시작 거리 9m, 접근 속도 2.3m/s입니다. 준비 시작 시 방향을 고정하고 1.35초 동안 바닥 긁기와 고개 숙이기로 예고합니다. 바닥에 돌진 폭을 표시하는 분홍색 선이 나타나며 발밑 꽃잎이 튑니다.

돌진 속도 9m/s, 최대 거리 7m, 타격 반경 0.38m, 피해 7입니다. 돌진 시작 후 플레이어를 따라 방향을 바꾸지 않습니다. 이동 구간 전체를 검사하고 한 번의 돌진에서는 피해를 한 번만 적용합니다. 벽이나 NavMesh 경계를 만나면 일찍 정지합니다. 돌진 중에는 꽃잎이 흩날립니다.

돌진이 끝나면 1초 동안 정지한 뒤 추적 상태로 돌아가며, 다음 공격까지 1.1초의 추가 쿨타임이 있습니다. 체력은 32입니다. 비활성화/사망/대상 상실 시 예고선과 이펙트를 종료합니다.

기존 StageEnemy, CombatHealth, CombatProjectile 코드는 수정하지 않았습니다. 플레이용 씬에는 배치하지 않았습니다. 사용할 씬에 NavMesh가 필요합니다.

## 검증

- Unity 앞/옆 시점에서 준비·고개 숙이기·돌진·회복 자세 확인: `AnimationPreview.png`.
- 같은 돌진의 충돌 처리를 반복해도 피해 7만 적용, 옆으로 벗어난 대상 피해 0.
- 준비 중 대상이 옆으로 움직여도 방향 변화 0도.
- 얇은 벽을 구간 검사로 감지하고, 취소 시 예고선/파티클 종료 확인.
- 별도 임시 NavMesh를 만든 실행 검사에서 직선 7.00m 이동 후 회복 상태 진입. 옆으로 피한 대상의 체력 유지.
- 3m 앞에 두께 0.1m 벽을 둔 실행 검사에서 약 2.11m 이동 후 벽 앞에서 회복 상태 진입. 측정은 후속 추적 이동 전에 기록했습니다.
- Unity 오류 로그 0건. 검증 후 실행 모드를 종료했습니다. 실제 Spring 방의 지형과 몬스터 조합으로 전투 밸런스를 확인한 것은 아닙니다.
- 상세 측정: `Verification.txt`. 편집 모드에서 NavMeshAgent가 활성화되지 않은 초기 검사는 이후 실행 검사로 보완했습니다.
