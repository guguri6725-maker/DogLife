# 꽃 갑옷 해골 몬스터

- 프리팹: `Assets/Prefabs/monster/BlossomSkeleton.prefab`. 기존 씬 배치나 일반 몬스터는 교체하지 않았습니다.
- 모델/재질/클립: `Assets/Art/Enemies/BlossomSkeleton/`. Downloads 원본 FBX는 수정하지 않았습니다.
- 바닥 및 공중에 분리된 꽃잎 14개 조각(872개 원본 정점)을 제거했습니다. 연결된 갑옷·몸체·검의 꽃 장식은 유지했습니다.
- 원본 검의 일부가 다리 뼈에 연결되어 있던 가중치를 오른손으로 보정했습니다.
- 기존 리그를 사용하여 Idle 2.4초, Walk 1초, Attack 1.05초를 제작했습니다. Idle/Walk는 반복, Attack은 1회입니다. Generic Animator와 `Moving`/`Attacking` Bool을 사용하고 Root Motion은 끕니다.
- Attack: 0–0.40초 크게 들어 올리기 → 0.40–0.47초 유지 → 0.47–0.63초 전방 베기 → 1.05초까지 자세 복귀 → 0.20초 후딜 → 추적 재개. 타격은 0.61초에 한 번입니다.
- `StageEnemy.cs`는 사용자 요청에 따라 수정하지 않았습니다. 새 `BlossomSkeletonEnemy`만 해골 프리팹에 연결했습니다. 기존 몬스터와 같은 CombatHealth, NavMeshAgent, Animator 파라미터, 체력바/공격 예고 표시 방식을 사용합니다.
- 감지 13m, 이동 속도 2, 공격 시작 거리 1.7m, 타격 거리 2m, 전방 부채꼴 100도, 피해 5입니다. Inspector에서 조정할 수 있습니다. 타격 시점에는 방향을 고정하며, 사거리 이탈·후방·벽 뒤의 플레이어는 맞지 않습니다. 애니메이션을 변경하면 hitTime과 attackDuration도 맞춰야 합니다.

## 검증

- 세 클립의 뼈 경로 누락 0, Idle/Walk 반복 경계의 뼈 회전 차이 0도.
- 격리한 프리팹 로직 검사: 전방에서만 피해 5, 같은 공격의 물리 처리 3회에도 추가 피해 없음. 후방/사거리 밖/벽 뒤에서는 피해 0.
- Unity에서 클립별 실제 변형 메시를 렌더링하여 걷기 및 검 들어 올리기/베기/복귀 자세 확인.
- 공격 자세에서 모델이 잘리지 않도록 전체 클립의 변형 범위를 포함하는 스킨 bounds 적용.
- 결과: `Verification.txt`, `AnimationPreview.png` (위 Attack, 아래 Walk).
- 씬에 배치하지 않는 프리팹 전용 작업이므로 실제 스테이지에서 추적 경로와 전투를 직접 조작한 검증은 하지 않았습니다. 사용 씬에 해당 NavMesh가 필요합니다.

생성 도구: `Tools/build_blossom_skeleton.py` 및 `BlossomSkeletonBuilder.cs`. 중간 Blender 작업 파일은 `Library/BlossomSkeleton/`에 있습니다.
