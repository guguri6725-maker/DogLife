## 참고 이미지 기반 내려베기 및 공격 이펙트

- 검의 방향을 단순 보간하던 방식을 바꿔 머리 뒤 → 정수리 위 → 전방 → 바닥 순서로 회전하는 궤적을 적용했습니다. 양손 손잡이 간격은 검사 시 최대 약 0.111m입니다.
- 실제 Attack 클립에서 검끝과 손잡이 위치 100개를 추출해 분홍색 넓은 잔상, 밝은 칼날 테두리, 잠깐 흩어지는 꽃잎을 표시합니다. 1.25초에 바닥 충격파가 생깁니다.
- 꽃잎은 공격 이펙트로만 잠깐 표시하며 대기 상태의 공중/바닥 장식 꽃잎은 추가하지 않았습니다.
- 전용 BlossomSkeletonAttackVfx를 프리팹에 연결했습니다. StageEnemy 및 기존 해골 전투 스크립트는 수정하지 않았습니다. 타격 시점만 프리팹에서 1.25초로 맞췄습니다.
- Animator 구동 시 표시, 공격 취소 시 숨김, 공격 종료 후 숨김, 다음 공격 재표시를 확인했습니다. 이펙트는 한 개 메시로 표시되며 확인한 타격 프레임은 598정점입니다. Unity 컴파일 오류 0건입니다.
- 프리팹 렌더링 검증 이미지: BlossomAttackVFX.png. 검사 기록: TwoHandVerification.txt. 실제 스테이지 조작 검증은 하지 않았습니다.
- Attack 클립을 다시 만들었을 때 DogLife/Monsters/Update Blossom Slash VFX 메뉴로 궤적과 프리팹 설정을 다시 추출할 수 있습니다.
# 꽃 갑옷 해골 몬스터

## 양손 내려찍기 변경

현재 Attack은 1.65초의 양손 내려찍기입니다. 0–0.55초 양손으로 잡고 머리 뒤로 들어 올리기, 0.55–0.95초 유지, 0.95–1.25초 머리 위를 지나는 큰 호로 내려찍기, 1.28초까지 마무리 자세, 1.65초까지 대기 자세 복귀 후 기존 0.2초 후딜을 사용합니다. 타격 시점은 프리팹의 hitTime=1.25, attackDuration=1.65로 맞췄습니다. 전투 스크립트는 변경하지 않았습니다.

양팔 위치를 계산해 손잡이 간격을 유지하고 클립으로 베이크했습니다. 유지/타격 시점의 양손 간격은 0.110m, 시작/끝 뼈 회전 차이는 0도이며 반복하지 않습니다. 크게 들어 올릴 때 검이 늘어나던 원본 가중치도 추가 보정했습니다. 결과는 `TwoHandAttack.png`, `TwoHandVerification.txt`입니다. 아래 초기 Attack 길이/타이밍은 최초 제작 기록이며 이번 변경으로 대체됩니다.

## 얼굴 방향 수정

원본 조형에 포함된 약 35도의 옆보기 방향을 보정했습니다. Idle/Walk/Attack의 머리 곡선과 프리팹 기본 머리 자세에 적용했으며, 몸통의 보행 흔들림/공격 회전을 머리에서 보상해 정면 시선을 유지합니다. StageEnemy 및 해골 전투 스크립트는 변경하지 않았습니다. `HeadDirectionFixed.png`는 Idle / Walk / 공격 준비 / 타격 시점 비교입니다. `HeadDirectionVerification.txt`에 회전 검사를 기록했습니다.

- 프리팹: `Assets/Prefabs/monster/BlossomSkeleton.prefab`. 기존 씬 배치나 일반 몬스터는 교체하지 않았습니다.
- 모델/재질/클립: `Assets/Art/Enemies/BlossomSkeleton/`. Downloads 원본 FBX는 수정하지 않았습니다.
- 바닥 및 공중에 분리된 꽃잎 14개 조각(872개 원본 정점)을 제거했습니다. 연결된 갑옷·몸체·검의 꽃 장식은 유지했습니다.
- 원본 검의 일부가 다리 뼈에 연결되어 있던 가중치를 오른손으로 보정했습니다.
- 기존 리그를 사용하여 Idle 2.4초, Walk 1초, Attack 1.05초를 제작했습니다. Idle/Walk는 반복, Attack은 1회입니다. Generic Animator와 `Moving`/`Attacking` Bool을 사용하고 Root Motion은 끕니다.
- Attack: 0–0.40초 크게 들어 올리기 → 0.40–0.47초 유지 → 0.47–0.63초 전방 베기 → 1.05초까지 자세 복귀 → 0.20초 후딜 → 추적 재개. 타격은 0.61초에 한 번입니다.
- `StageEnemy.cs`는 사용자 요청에 따라 수정하지 않았습니다. 새 `BlossomSkeletonEnemy`만 해골 프리팹에 연결했습니다. 기존 몬스터와 같은 CombatHealth, NavMeshAgent, Animator 파라미터, 체력바/공격 예고 표시 방식을 사용합니다.
- 감지 13m, 이동 속도 2, 공격 시작 거리 1.7m, 타격 거리 2m, 전방 부채꼴 100도, 피해 5입니다. Inspector에서 조정할 수 있습니다. 타격 시점에는 방향을 고정하며, 사거리 이탈·후방·벽 뒤의 플레이어는 맞지 않습니다. 애니메이션을 변경하면 hitTime과 attackDuration도 맞춰야 합니다.

## 검증

- 세 클립의 뼈 경로 누락 0, Idle/Walk 반복 경계의 뼈 회전 차이 0도.
- 격리한 프리팹 로직 검사: 전방에서만 피해 5, 같은 공격의 물리 처리 3회에도 추가 피해 없음. 후방/사거리 밖/벽 뒤에서는 피해 0.
- Unity에서 클립별 실제 변형 메시를 렌더링하여 걷기 및 검 들어 올리기/베기/복귀 자세 확인.
- 공격 자세에서 모델이 잘리지 않도록 전체 클립의 변형 범위를 포함하는 스킨 bounds 적용.
- 결과: `Verification.txt`, `AnimationPreview.png` (위 Attack, 아래 Walk).
- 씬에 배치하지 않는 프리팹 전용 작업이므로 실제 스테이지에서 추적 경로와 전투를 직접 조작한 검증은 하지 않았습니다. 사용 씬에 해당 NavMesh가 필요합니다.

생성 도구: `Tools/build_blossom_skeleton.py` 및 `BlossomSkeletonBuilder.cs`. 중간 Blender 작업 파일은 `Library/BlossomSkeleton/`에 있습니다.
