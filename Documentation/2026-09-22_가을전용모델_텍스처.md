# 가을 전용 모델·텍스처 교체

- 적용 씬: `Assets/Scenes/Stage3_Fall.unity` 및 `AutumnJourney9`의 9개 방.
- 기존 Fall 장식 메시를 전부 배치에서 제거하고 Blender에서 직접 제작한 구조물로 교체했습니다. 원본 공용 에셋은 다른 씬을 위해 보존합니다.
- 새 모델: 단풍나무 3종, 원거리 나무, 석등, 쓰러진 목재, 뿌리 그루터기, 목제 표지, 봉헌 제단, 길표석.
- 나무는 가지 분기·뿌리·구부러진 잎 메시·겹치는 수관으로 구성했습니다. 가까운 나무는 15,616 삼각형, 먼 나무는 4,096 삼각형이며 LODGroup으로 전환합니다.
- built-in image_gen으로 단풍잎(투명 잎맥 텍스처), 단풍나무 껍질, 풍화된 돌 텍스처를 새로 생성했습니다. Unity 최대 크기는 1024, 밉맵 사용입니다.
- 생성 프롬프트: `ArtSource/AutumnCrafted/TexturePrompts.md`.
- Blender 원본: `ArtSource/AutumnCrafted/AutumnCrafted.blend`. 제작 스크립트: 같은 폴더의 `build_autumn.py`.
- Unity 모델·텍스처·재질·나뭇잎 셰이더: `Assets/Art/AutumnCrafted`.
- 덩굴문 외형을 직접 만든 목제 미닫이문으로 교체했습니다. `AutumnGateVisual`은 기존 `VineGate.Progress`에 맞춰 열리고 닫힙니다. 기존 충돌과 방 전환 상태는 유지합니다.
- 봄에서 공유하는 바닥·경계 벽 재질, 5번째 왼쪽 상점, 7번째 오른쪽 합성방, 9단계 단풍 색상은 유지했습니다.
- 새 구조물 위치에 맞춰 방별 내비게이션을 다시 베이크했습니다.
- 프로젝트 재생 검사 결과는 문 통과와 몬스터 생성 중심입니다. 배포 빌드의 FPS 측정은 별도로 진행하지 않았습니다.
